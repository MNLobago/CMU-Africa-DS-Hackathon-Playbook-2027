## 🧪 Smoking Status Binary Classification (Bio-Signals)

This repository contains our approach to the **CMU Africa Data Science Challenge: *Can you predict a smoker’s status with bio signals?***, a **binary classification** problem focused on predicting whether an individual is a smoker based on physiological and medical measurements.

The challenge uses **synthetic bio-signal data** (e.g., cholesterol, liver enzymes, blood pressure), generated to preserve realistic patterns while ensuring privacy and fair competition. Models are evaluated using **ROC AUC**, emphasizing probability ranking rather than hard class predictions.

This directory documents the **modeling strategy, feature engineering, and validation pipeline** used for the competition. Due to competition rules and disclosure constraints, the focus is on the **approach rather than guaranteed leaderboard replication**, though the methods are reproducible and transferable to similar healthcare classification tasks.
